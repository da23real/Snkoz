# Snkoz R21 - quick guide

[Video](https://youtu.be/prQQBhpKYqU) · [Detailed French guide](README_FR.md)

Open a Montage block's effects table, add video/MIDI sources explicitly and connect effects, text or animations. Select channel/note/CC and parameter ranges; descending ranges reverse the mapping. Generic animation presets need your own images.

CC text shows controller number, value, or both. Guided mode preserves readability; free values allow extremes. Parameter visibility does not choose MIDI channels. Project choices take priority over defaults.

Independent CC passes can be recorded with preview or without video computation, optionally listening to audio. Accepting a pass creates a separate MIDI track. Pausing preview does not add events.

R21 adds separate audio/video mutes, reorderable audio treatments, minimum duration for MIDI source changes, idle-animation silence threshold, direct source playback and per-track oriented thumbnails. Direct playback shows original media without effects. Table undo covers two module deletions; mute is toggled directly.
