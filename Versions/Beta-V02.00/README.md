# Snkoz Beta V02.00

Application Windows **VA01.60 R99**, build **10.1.60.99**. Le numéro de bêta publique correspond à celui d’UrbanKaoz. [UrbanKaoz Beta V02.00](https://github.com/da23real/UrbanKaoz/releases/tag/beta-v02.00)

[Télécharger Snkoz pour Windows](https://github.com/da23real/Snkoz/releases/download/beta-v02.00/Snkoz-Beta-V02.00-Windows.zip) · [Installation pas à pas](INSTALLATION.md) · [Publication et empreintes](https://github.com/da23real/Snkoz/releases/tag/beta-v02.00)

La prise vidéo multicaméra, la synchronisation MIDI et le montage au contrôleur MIDI sont les fonctions principales. Le montage avec effets et animations pilotés en MIDI est en cours de mise au point et fera l’objet d’un correctif.

**Limite connue.** Pour le transport MIDI dans Composition, le CC appris doit aussi correspondre à une affectation MIDI du projet. La liaison série avec Tee VA01.60 a été vérifiée dans les sources.
