# Contributing to Snkoz

## 1. Suggestions and bugs / Idées et bugs

Use the Issues tab of https://github.com/da23real/Snkoz. Include the Snkoz
version, operating system, steps, expected result and actual result. Screenshots
are useful. Do not upload private recordings, credentials or signing keys.

Les idées et signalements sont les bienvenus en français ou en anglais.
Un ticket ne modifie pas le logiciel : il permet de discuter et de suivre le sujet.

## 2. Code contributions

Read LICENSE. Fork on GitHub, create a branch, make a focused change and open
a pull request against this repository. Keep contribution forks clearly
unofficial and do not publish independent installers or releases.

Explain the problem, changes and validation. Keep the prototype responsive:
two structural undo levels, no full MIDI copy or synchronous disk save for
each move/mute. Keep manual projects separate from recovery files. Preserve
exact MIDI timing and document incompatible project formats explicitly.

Only Windows and the Android USB camera companion belong here. Do not add
Arduino/Teensy/Pico firmware or device images. The Windows hardware-controller
interface is application code; it does not imply that device firmware may be
uploaded. Never add private settings, media, keys or SDK binaries.

You retain your contribution's ownership. Submission grants the permissions
described in LICENSE, including inclusion in official releases under the same
license. Declare third-party code and its license. Maintainers review and
choose whether to merge; a contribution is not automatically an official release.
